## Choose how much you own

Each level hands you one more layer of the stack. Move between them by changing
Layers; nothing that calls auth has to change.

<OwnershipLadder />

## One contract, every call site

Declare session claims and the actions clients may call. Your server, its HTTP
routes, and your client all use the same definition.

<CallSites
  sites={[
    { label: "Server handler", code: "yield* auth.signIn({ email, password })" },
    { label: "HTTP route", code: "POST /auth/signIn" },
    { label: "Client Effect", code: "yield* client.auth.signIn({ email, password })" },
    { label: "React", code: "const [result, signIn] = useAtom(auth.signIn)" },
  ]}
>
  <Snippet src="../README.md" region="auth-contract" />
</CallSites>

Each call takes the same input and returns the same typed result or failure.
Clients can reach only the actions you declare.

Each method adds the services it needs to the type of `AppAuth.layer`, so the
compiler lists what your application still has to provide. Publish the actions
your client needs through a [shared contract](/auth/guide/http-and-client/).
